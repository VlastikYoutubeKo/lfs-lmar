📝 Multi-Layer Workflow
1
Click Add Layer and load each trip recording as a separate layer.
2
Each layer gets a unique color. Toggle visibility with the 👁️ button.
3
Click a layer to make it active. Only the active layer can be annotated.
4
Select a Turn Type (keys 1-6) and click on the path.
5
When finished, Export ML Dataset combines all layers.
