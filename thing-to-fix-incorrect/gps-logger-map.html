🔴 Recording Workflow
1
Run the LFS-LMAR Server (Node.js bridge).
2
Connect LFS to a [TC] Server (e.g., CityDriving).
3
Wait for the Green Dot in top-left (WebSocket Connected).
4
Click REC and drive your desired path/turn.
5
Click Save JSON. This file will be used in the Annotator.
